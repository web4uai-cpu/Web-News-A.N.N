# Admin Dashboard

Internal admin panel for managing the A.N.N. platform.

## Tech (planned)
- Next.js + TypeScript + TailwindCSS (shared stack with web/)
- Role-based access (super admin, editor, viewer)

## Screens (planned)
- System health overview
- Pipeline control and monitoring
- Content moderation queue
- User management
- API key management
- Agent performance metrics
- Billing and revenue dashboards
