# Docker Compose Configs

Multi-service Docker Compose files for local development and staging.

## Files (planned)
- `docker-compose.dev.yml` — all services with hot reload
- `docker-compose.staging.yml` — production-like with resource limits
- `docker-compose.monitoring.yml` — Prometheus + Grafana + alerting

See root `docker-compose.yml` for the current monolith setup.
